# Project Statement

## Problem Statement
Students often record small daily expenses in scattered notes or apps, making it difficult to see where money is going. This project provides a simple command-line expense tracker that stores expenses and produces category and monthly summaries.

## Scope
The system supports adding, listing, deleting, validating, persistently storing, and analyzing personal expense records. It is intentionally a local CLI application and does not include banking integration, cloud synchronization, or multi-user authentication.

## Target Users
- College students
- Users who want a lightweight local expense tracker
- Beginners learning Python application structure

## High-Level Features
1. Expense CRUD-style management (create, read, delete)
2. Input validation for dates, categories, and amounts
3. JSON persistence
4. Category-wise analytics
5. Monthly spending analytics
6. Top-category summary
7. Automated unit tests
